# 🎒 Mochila Hacker: Gadgets de Exploração

Ferramentas físicas (Hardware Hacking) utilizadas para testar a segurança de perímetros e dispositivos.

### 🐬 Flipper Zero
O "canivete suíço" multiuso com interface de tamagotchi.
* **Capacidades:** Clona cartões NFC/RFID, copia controles de garagem (Rádio), infravermelho e Bluetooth.

### 🦆 USB Rubber Ducky
O mestre da engenharia social.
* **Como funciona:** O computador o reconhece como um **teclado**. Ao plugar, ele digita scripts em velocidade sobre-humana para criar backdoors ou roubar credenciais em segundos.

### 💳 M5Stick Card
Focado em ataques de proximidade.
* **Uso:** Altamente customizável para ataques a redes Wi-Fi e Bluetooth. Possui teclado completo e tela em um formato extremamente portátil.
