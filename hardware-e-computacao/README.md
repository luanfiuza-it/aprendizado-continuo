# ⚙️ Hardware e Computação: Por trás do Gabinete

Entender como o hardware funciona é o primeiro passo para realizar diagnósticos precisos e entender vulnerabilidades de baixo nível.

## 🧩 O que é um computador?
| Componente | Função |
| :--- | :--- |
| **Processador (CPU)** | O cérebro. Realiza cálculos e toma decisões. |
| **RAM** | Memória volátil e rápida para arquivos temporários. |
| **ROM/Storage** | Onde os dados são gravados permanentemente. |
| **Motherboard** | A "estrada" que liga todos os componentes fisicamente. |
| **GPU** | Especialista em processamento de vídeo e renderização 3D. |
| **Fonte** | O coração que bombeia energia para o sistema. |

## 🛠️ A Trindade da Computação
1.  **Hardware:** A parte física (o que a gente chuta).
2.  **Software:** O que instalamos (SO, Navegadores, Apps - o que a gente xinga).
3.  **Firmware:** O tradutor. Software embarcado (como a **BIOS**) que diz ao hardware como ele deve se comportar e entender periféricos como mouse e teclado.
