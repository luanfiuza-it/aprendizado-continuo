# 🔢 Sistemas Numéricos
Uma análise sobre como as máquinas interpretam, armazenam e processam dados na essência do hardware.

### 🟢 Binário (Base 2)
A linguagem nativa do computador, composta apenas por impulsos elétricos (0 e 1).
* **Processamento:** Tudo o que o processador executa é convertido para binário.
* **Redes:** Fundamental para cálculo de máscaras de sub-rede e IPs.

### 🔵 Decimal (Base 10)
O sistema padrão humano (0 a 9).
* **Interface:** Usado para facilitar a nossa interação com a máquina, sendo convertido pelo sistema na entrada e saída de dados.

### 🟣 Hexadecimal (Base 16)
Sistema de compactação do binário, usando números (0-9) e letras (A-F).
* **Aplicações:** Essencial para representar endereços de memória, endereços físicos de rede (MAC Address) e chaves de criptografia de forma legível.

### 🟠 Octal (Base 8)
Sistema numérico que utiliza os dígitos de 0 a 7, criado para encurtar o código binário agrupando-o de três em três bits.
* **Histórico:** Foi muito popular na programação de computadores antigos e mainframes.
* **Sistemas e Segurança:** Hoje, sua principal aplicação prática é no ecossistema Linux/Unix para definir **permissões de arquivos e pastas** (ex: o famoso comando `chmod 777` ou `chmod 644`), onde cada número octal representa um conjunto de permissões (leitura, escrita e execução).
