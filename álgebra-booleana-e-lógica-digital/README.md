# 🔌 Álgebra Booleana e Lógica Digital
A matemática baseada em Verdadeiro (1) e Falso (0) que dita o comportamento dos circuitos no nível físico.

### ⚖️ A Lógica da Máquina
O hardware não entende incertezas. Toda decisão é estritamente binária e processada por portas lógicas feitas de transistores.
* **Eficiência:** Leis booleanas (como a de De Morgan) são usadas para simplificar circuitos, otimizando o espaço no chip de silício.

### 🚪 Portas Lógicas Principais
Os operadores que manipulam o tráfego dos bits:
* **AND (E):** Só é verdadeiro se TODAS as entradas forem 1.
* **OR (OU):** É verdadeiro se PELO MENOS UMA entrada for 1.
* **NOT (NÃO):** Inverte o sinal (de 1 para 0 e vice-versa).
* **XOR (Ou Exclusivo):** Verdadeiro apenas se as entradas forem diferentes. É a espinha dorsal de muitos algoritmos de cifra de fluxo e criptografia moderna.
