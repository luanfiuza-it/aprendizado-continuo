# 🌐 Fundamentos de Redes de Computadores
Conceitos essenciais sobre como os dispositivos se conectam e trocam informações em escala global.

### 🥪 Modelo OSI e TCP/IP
As camadas que padronizam a comunicação em rede.
* **Modelo OSI:** Dividido em 7 camadas (Física, Enlace, Rede, Transporte, Sessão, Apresentação e Aplicação).
* **Modelo TCP/IP:** A arquitetura prática da Internet, simplificada em 4 camadas.

### 📬 Protocolos e Endereçamento
As regras de etiqueta e identificação na rede.
* **IPv4 e IPv6:** Sistemas de endereçamento para localizar dispositivos.
* **Protocolos Comuns:** * **HTTP/HTTPS:** Navegação web segura.
    * **DNS:** Tradução de nomes (ex: google.com) para endereços IP.
    * **DHCP:** Atribuição automática de IPs na rede.

### 🛡️ Dispositivos de Interconexão
O hardware que move os dados.
* **Roteadores:** Decidem a melhor rota para os pacotes entre diferentes redes.
* **Switches:** Conectam dispositivos dentro de uma mesma rede local (LAN).
* **Firewalls:** Filtram o tráfego com base em regras de segurança para proteger a rede.
